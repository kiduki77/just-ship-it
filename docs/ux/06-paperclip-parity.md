# 06. Paperclip 수준 맞추기

2026-11-01, 오너 요청: "이런 시스템에 필요한 기능인데 UI에 없어서 구현 안 된 것이 많고, 대시보드가 만들다 만 느낌이다. 적어도 Paperclip의 완성도를 목표로."

Paperclip(paperclipai/paperclip, docs.paperclip.ing)은 AI 에이전트로 회사를 운영하는 오픈소스 오케스트레이터입니다. 이 문서는 Paperclip 운영 화면이 오너에게 주는 기능을 Just Ship It의 모델에 맞춰 비교하고, 이번에 구현한 것과 일부러 뺀 것을 기록합니다.
조사 출처: README, 대시보드·승인·비용·업무·프로젝트·활동 로그 문서(v2026.1023.0). 에이전트·조직·목표·명령 팔레트 문서는 읽지 못해 추정하지 않았습니다.

## 기능 비교

| Paperclip | 이전 콘솔 | 지금 (`feat/console-v2`) |
|---|---|---|
| 대시보드: 에이전트 패널, 4개 요약 카드, 예산 경고 배너, 14일 차트 3개, 최근 활동, 최근 업무 | 지표 4개와 프로젝트 카드 | 홈: 손볼 일(실패·멈춤·예산), 결정 대기, 요약 4칸(에이전트·업무·월 사용·결정 대기), 지난 확인 이후 변화, 프로젝트 상태 줄, 14일 차트 4개(실행 성공·실패, 끝난 업무, 성공률, 사용량), 에이전트 실시간 상태, 최근 활동, 최근 업무 |
| Inbox: 내 할 일·실패 실행·알림 | 승인 센터(요청만) | 결정함: 대기 / 알림(실패 업무·멈춘 실행·개발 실패·예산 경고, 각각 바로 처리 버튼) / 처리됨(오너 결정과 시스템 처리 분리) |
| 승인: Approve·Reject·Request revision, 코멘트 | 승인·답변·보류·반려, 메모 | 같음 + 결정 패널 상시 노출, 누르기 전 결과 미리보기, 인용 근거 확신도 막대 |
| Tasks: 목록·보드, 필터·검색·그룹 | 프로젝트별 칸반만 | 회사 전체 업무: 상태 그룹·담당·검색·목록/보드, 오른쪽 상세 |
| Task 상세: 속성 편집, 재할당, 중지·재개, 코멘트, 하위 업무 | 읽기 전용 | 다시 시도, 시작 전 업무 고치기(제목·목표·기준·담당), 취소, 오너 코멘트(다음 시도 프롬프트에 들어감), 업무 추가(선행 업무 지정), 실행 기록·요청·활동 타임라인 |
| 프로젝트 목록·예산·보관/해제 | 사이드바 목록, 보관 | 프로젝트 화면(진행·완료·보관 탭), 상태 줄·단계 표시, 예산 변경, 이름 변경, 보관 해제 |
| 일시정지·재개·종료 | 없음 | 프로젝트 일시정지(진행 중 업무는 끝나고 새 업무는 시작 안 함)·재개, 실패한 실행 다시 시작 |
| 예산: 회사·에이전트·프로젝트, 80% 경고, 100% 정지, "예산 올리고 재개" | CLI로만 | 회사 월 한도 변경, 프로젝트 예산 변경 + 예산 정지 시 "예산 늘리고 재개"(예산 때문에 실패한 업무도 재시도), 80% 경고 |
| Costs: 기간별·제공자·모델 | 에이전트별 표 | 30일 추이, 프로젝트·에이전트·모델·용도별, 월별 |
| Audit: 활동(필터·CSV 내보내기), Runs | 없음 | 활동 기록(모든 상태 변화가 자동 기록, 과거 기록 복원, 필터, CSV), 실행 기록(모든 모델 호출, 실패 사유), 실행 상세(보낸 프롬프트·응답), 워커 작업 대기열 |
| Agents 목록·상세, 상태(Active/Running/Error/Paused) | 조직도 | 에이전트 목록(상태·지금 하는 일·24시간 실행·월 사용), 상세(14일 차트, 용도별, 맡은 업무, 최근 실행, 스킬, 역할 프롬프트) |
| 명령 팔레트, 단축키 | j/k | Ctrl+K: ID(P·T·REQ·EV·DEC·J·M)로 바로 가기, 제목·근거 검색, 화면 이동 |
| 실시간 갱신, 변경 알림 | SSE 갱신 | 같음 + 구석 알림(새 차단 요청, 실패, 프로젝트 완료·정지) |
| 설정 | 없음 | 운영 정책 읽기 화면(한도, 승인 정책, 제공자, 개발 격리, 에이전트 구성) |
| 모바일 | 900px 이하 한 줄 | 결정 버튼을 화면 아래 고정, 열린 요청이 목록보다 먼저 |

## 일부러 뺀 것

| Paperclip 기능 | 뺀 이유 |
|---|---|
| 에이전트 단위 일시정지·해고·직접 고용 | 이 시스템의 실행 단위는 에이전트 하트비트가 아니라 프로젝트 그래프입니다. 에이전트 하나를 멈추면 그 업무를 기다리는 그래프가 CEO 검토로 넘어가 버립니다. 멈춤은 프로젝트 단위로 제공합니다. |
| 에이전트별 월 예산 | 예산 단위가 회사·프로젝트·업무로 이미 강제됩니다(`services/budget.py`). 에이전트별 사용량은 보여 주되 한도는 두지 않았습니다. |
| 정책·설정 편집 화면 | `config/*.yaml`은 "에이전트가 바꿀 수 없다"는 것이 보안 경계입니다. 콘솔은 읽기만 하고, 바꾸는 것은 오너의 파일 편집으로 남겼습니다. |
| 다중 회사, 권한·역할, 비밀 관리 | 오너 한 명이 쓰는 로컬 콘솔입니다(PRODUCT.md). |

## 백엔드 추가

- `activity_events`: 세션 훅이 프로젝트·업무·요청·결정·개발 작업·명세·스킬의 생성과 상태 변화를 행위자와 함께 기록합니다. 마이그레이션이 기존 타임스탬프로 과거 기록을 채웁니다(`data.backfill = true`).
- `services/control.py`: 오너 동작. 콘솔 API는 `activity.as_actor("owner")` 안에서 호출해 감사 기록에 오너로 남습니다.
- 그래프: 일시정지는 `schedule`과 게이트(`plan_gate`, `human_gate`, `final_gate`)에서 걸립니다. CEO 검토 중에 오너가 업무를 추가하거나 재시도하면 마감 전에 그 업무를 먼저 돌립니다.
- 재정렬(`realign`)이 요청 응답뿐 아니라 독립 지시로도 돕니다.
- 테스트: `tests/test_console.py` 22개.
